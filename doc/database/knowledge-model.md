# Physics Knowledge Model

## Core Entities

- **Topic:** a curriculum area such as Mechanics or Electricity.
- **Concept:** a specific idea such as velocity or Newton's second law.
- **Question:** a prompt that tests one or more concepts.
- **Attempt:** a student's submitted answer, planned for a later phase.
- **Learning record:** evidence of mastery or difficulty, planned for analytics.

## Question Types

- MCQ
- Written explanation
- Numerical problem

## Future Enhancements

- Prerequisite relationships between concepts
- Difficulty and curriculum tags
- Formula and unit-aware numerical evaluation
- Rubric-based written-answer evaluation
